FLAGSHIP · AUTONOMOUS AI ENGINEERING

ORION — AI Engineering Control Center

An automated RAG experimentation platform that creates retrieval hypotheses, runs controlled experiments, evaluates results, stores experiment history, and keeps a human approval step before changes are accepted.

9 + 4 public and held-out evaluation items Human-gated deployment decisions
InvestigateHypothesizeExperimentRememberApprove

Reported gains: +33.3% retrieval recall and +15.2% answer F1. Evaluation scope: 9 public and 4 held-out items; not a broad production benchmark.

  • FastAPI

  • BM25
  • TF-IDF
  • Docker

  • JWT
View architecture
Problem

RAG changes are often accepted without controlled measurement or memory of failed ideas.

Approach

Investigate → hypothesize → experiment → remember → request human approval.

Verification

Retrieval recall and answer F1 across separate public and held-out evaluation sets.

Delivery

Docker images published through GitHub Actions and deployed to Azure Container Apps.
